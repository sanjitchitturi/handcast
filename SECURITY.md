# Security reporting

Do not post credentials, private video, biometric landmarks, robot credentials, or exploitable
vulnerability details in public issues. Use GitHub's **Report a vulnerability** option in the
repository Security tab. If it is not available, use a private contact method listed on
GitHub before sharing sensitive details.

Include the affected revision, impact, prerequisites, and a minimal reproduction using synthetic
trajectory data. Do not attach video of identifiable people or robot-control credentials.

Security fixes target the default branch. The numerical safety checks in this project are not a
hardware safety certification.
